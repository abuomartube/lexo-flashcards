# @workspace/flashcards-ui

Reusable React components for the LEXO Flashcards experience, designed to be embedded natively in host apps such as EduLexo.

**Status: L1 scaffolding only.** This package is currently empty (only a version constant is exported). Components, hooks, and the `<FlashcardsApp />` root will be added in L2 of the Phase 2 plan.

Do not depend on this package from production code yet.
